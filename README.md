# 🌻 Flores Amarillas para Lucy 💛

Una hermosa página web interactiva con flores amarillas, girasoles dorados, música relajante y una carta dedicatoria para **Lucy**.

## ✨ Características

- 🌻 **Ramo Radiante & Girasoles Interactivos**: Ilustración artística y ramo SVG animado que baila con el viento.
- 💌 **Carta Especial para Lucy**: Hermosa carta de pergamino con versos célebres y dedicatoria permanente con sello dorado.
- 🎵 **Melodía Mágica**: Sintetizador con Web Audio API puro que reproduce una dulce melodía al estilo de caja de música.
- 💐 **Lluvia de Flores**: Lluvia de pétalos dorados en pantalla.
- 📱 **100% Responsivo**: Diseñado y adaptado para teléfonos móviles (iPhone, Android) y pantallas de escritorio.
- 🖐️ **Jardín Interactivo**: Toca cualquier parte de la pantalla para hacer florecer nuevos girasoles con vibración háptica.

## 🚀 Tecnologías

- **HTML5** semántico y estructurado.
- **CSS3** puro (Glassmorphism, animaciones fluidas, paleta dorada nocturna).
- **JavaScript (ES6+)** y Canvas API para la física de pétalos y Web Audio API.
